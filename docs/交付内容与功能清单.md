# 交付内容与功能清单

## 系统组成

- 后端：FastAPI、SQLAlchemy、SQLite。
- 前端：Vue 3、Vite、Element Plus、Three.js。
- 运行方式：生产版前端和 API 由同一个本地服务提供。
- 数据库：一个经过路径迁移和历史任务整理的交付数据库。
- 运行环境：独立 Python 3.12 及项目依赖。

## 功能

- 管理员登录、注册、用户管理。
- 地质模型、钻孔、钻孔分段、化学钻孔和地质体管理。
- 岩性三维重建算法 A：CDT。
- 岩性三维重建算法 B：体素化与条件模拟。
- 岩性三维重建算法 C：Kriging 引导 MLP。
- 化学元素解释规则、背景值及统一六级颜色语义。
- 化学元素变化规律分析。
- 化学元素相关性、R 型聚类和共异常分析。
- 地质约束各向异性 IDW 单元素三维重建。
- 地质体、断层、项目钻孔、化验钻孔与浓度场叠加。
- PLY 预览、XYZ 坐标、正视/侧视/俯视和透明度控制。
- 找矿证据链、报告和结果下载。

## 化学元素覆盖

数据库包含 41 种元素：

`Ag, Al, As, Au, Ba, Bi, Ca, Cd, Ce, Cl, Co, Cr, Cu, Fe, Hg, K, La, Mg, Mn, Mo, Nb, Nd, Ni, P, Pb, Pr, Rb, S, Sb, Se, Si, Sn, Sr, Th, Ti, U, V, W, Y, Zn, Zr`

满足最少正值样本要求、可直接发起三维重建的元素为 38 种。Au、Hg、Mg 因正值样本不足保留在页面中并显示禁用原因。这是数据质量门槛，不是代码缺少元素。

已附带的当前算法三维结果：Fe、Ca、Cu、Rb、Si、Pb。
