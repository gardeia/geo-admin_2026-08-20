# 开发与部署说明

## 目录

- `backend/app`：后端 API、服务和算法源码。
- `backend/scripts`：数据库维护与交付辅助脚本。
- `backend/tests`：后端自动化测试。
- `backend/storage`：精选输入、结果和找矿分析产物。
- `frontend/src`：完整 Vue 前端源码。
- `frontend/dist`：已经构建的生产版前端。
- `runtime/python`：Windows 64 位独立 Python 环境。

## 交付运行

交付模式使用：

```text
runtime/python/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

工作目录必须是 `backend`。根目录的 `启动系统.bat` 已经完成目录、日志、健康检查和浏览器打开操作。

## 源码开发

如需重新开发前端，可在另行安装 Node.js 后进入 `frontend` 执行：

```text
npm install
npm run dev
```

如需使用系统 Python 重新建立后端环境，进入 `backend` 后执行：

```text
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 测试

```text
cd backend
..\runtime\python\python.exe -m unittest discover -s tests -v
```

批量为全部满足数据门槛的元素生成当前算法结果时，可从 `backend` 运行 `scripts/build_all_geochem_delivery.py`。该操作耗时且会产生大型中间文件，普通审查演示不需要执行。
