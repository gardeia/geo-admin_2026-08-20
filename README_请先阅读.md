# 地质模型管理系统：交付预检版

本目录是独立交付副本，可以整体移动到其他 Windows 10/11 64 位电脑。它包含完整前后端源码、数据库、生产版前端、Python 运行环境和精选演示结果，不需要安装 Node.js。

## 启动

1. 双击 `系统环境检查.bat`，确认三项文件、Python 依赖和数据库检查均通过。
2. 双击 `启动系统.bat`。
3. 浏览器将打开 `http://127.0.0.1:8000/login`。
4. 登录账号：`admin`；密码：`admin123`。
5. 使用结束后双击 `停止系统.bat`。

如果 8000 端口已经被其他程序占用，启动脚本会停止并提示，不会误用其他系统进程。运行日志保存在 `运行日志` 目录。

## 化学元素说明

- 数据库保存全部 41 种化验元素，页面全部列出。
- 其中 38 种满足当前规则要求的最少 30 个正值样本，可以由老师在页面中逐元素运行当前地质约束各向异性 IDW。
- Au、Hg、Mg 分别只有 1、12、10 个正值样本，低于规则门槛，因此页面保留元素但置灰，避免生成没有最低数据支撑的三维结果。
- 包内已有 Fe、Ca、Cu、Rb、Si、Pb 六个当前算法结果，可直接打开检查；其他满足条件的元素由使用者按需独立计算。

## 注意事项

- 请移动整个文件夹，不要单独移动 `backend`、`frontend` 或 `runtime`。
- 不要同时启动多份本系统。
- 三维重建计算时间取决于电脑性能，单元素任务产生的大型体素 CSV 属于运行期中间结果。
- 化学元素三维结果用于找矿空间核查参考，不等同于已圈定矿体。

详细内容见 `docs` 目录。
